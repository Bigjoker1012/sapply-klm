# ТЗ 4.11.1 — Диагностика белого экрана внутреннего Supply

**Дата:** 2026-09-20

---

## 1. ROOT CAUSE

**Base path mismatch.** Frontend HTML (`/sapply/`) ссылался на JS/CSS как `/assets/...` (от корня домена). Браузер запрашивал `http://192.168.51.240/assets/...`, но nginx не проксировал этот путь — он попадал в `location /` → `/var/www/html` → 404 → белый экран.

Та же проблема касалась API: JS `fetch('/api/...')` шёл на корень → 404.

На VPS это работало, потому что nginx проксирует `location /` → `:3001`. На внутреннем сервере основной location — `/sapply/`, а не `/`.

---

## 3. Что изменено

| Файл | На сервере | Изменение |
|------|-----------|-----------|
| `/etc/nginx/sites-enabled/klm-apps.conf` | 192.168.51.240 | Добавлены `location /assets/` и `location /api/` |

### Добавлено

```nginx
location /assets/ {
    proxy_pass http://127.0.0.1:3001/assets/;
    proxy_set_header Host $host;
    proxy_set_header X-Real-IP $remote_addr;
}

location /api/ {
    proxy_pass http://127.0.0.1:3001/api/;
    proxy_set_header Host $host;
    proxy_set_header X-Real-IP $remote_addr;
    proxy_read_timeout 300s;
    client_max_body_size 50m;
}
```

**No code changes. No frontend rebuild. No backend changes.**
