---

## 2. ДОПУСТИМЫЕ ЗНАЧЕНИЯ

### purchase_mode

| Значение | Описание |
|----------|----------|
| `exchange_to_market` | Биржа → внутренний рынок |
| `direct` | Прямая закупка |
| `import` | Импорт |
| `on_demand` | Под заявку |
| `do_not_purchase` | Не закупать |

### purchase_status

| Значение | Описание |
|----------|----------|
| `active` | Обычная закупка |
| `on_request` | Только под заявку |
| `blocked` | Закупка запрещена |
