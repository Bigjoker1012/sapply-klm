## 2. PG Functions

### getLiveStock()

Formula (identical to Sheets):

```
for each SKU:
  plant_qty  = latest PlantStock snapshot
  lip_qty    = latest LipStock snapshot  
  inbound_qty = SUM(in_transit WHERE status != 'received')
  base       = plant_qty + lip_qty
  consumed   = SUM(recipe_item.consumption_kg) WHERE recipe.status = 'active'
  available  = base + inbound_qty - consumed
  signal     = stockSignal(plant_qty + inbound_qty, lip_qty, consumed)
```

### getRecipeConsumption()

```sql
SELECT s.code, SUM(ri.consumption_kg) as total
FROM recipe_item ri
JOIN recipe r ON ri.recipe_id = r.id
JOIN sku s ON ri.sku_id = s.id
WHERE r.status = 'active' AND ri.consumption_kg > 0
GROUP BY s.code
```

### stockSignal()

```
available < 0    → critical
plant < consumed → transfer
otherwise        → ok
```

| Field | Sheets | PG |
