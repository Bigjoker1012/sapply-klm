Стоп. ТЗ 1.0 нельзя считать полностью пройденным до проверки бизнес-логики статуса.

В пользовательском интерфейсе обнаружен конкретный контрпример:

RAW_071 Буструм

потребность = 0
остаток после плана = 15 кг
закупка = 0
статус = «Срочно к закупке»

При этом RAW_071 отсутствует во всех рецептах.

В отчёте тестирования указана формула:

need_ratio = qty_today / avg_monthly_usage

и пороги:

ok > 1.5
control > 1.0
buy >= 0.6
urgent < 0.6

Проверь отдельно случаи:

avg_monthly_usage = 0
planned_need = 0
purchase = 0
stock > 0
позиция отсутствует во всех действующих рецептах.

Для каждого случая показать:

исходные данные;
рассчитанный need_ratio;
рассчитанный статус;
функцию и условие в коде.

Отдельно провести полную трассировку RAW_071 Буструм от источника появления до статуса Dashboard.

До выяснения этой ситуации вывод «систему можно использовать для реальных решений о закупке» считать неподтверждённым.

При этом остальные результаты ТЗ 1.0 сохранить без изменений.
