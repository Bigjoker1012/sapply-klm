## 1. Найденные проблемы

### 1.1 Статусы рецептов
**Проблема:** Frontend маппинг использовал русские названия (`план`, `в работе`, `архив`), а база данных содержала английские (`active`, `archived`). Из-за fallback `|| 'active'` все архивные рецепты отображались как активные.

**Данные в БД:**
- `active`: 24 рецепта
- `archived`: 167 рецептов
- Итого: 191 рецепт

### 1.2 Даты
**Проблема:** Часть дат хранится как Excel serial numbers (46269,46275,46273,46210), часть в нормальном формате (10.09.2026,14.09.2026).

**Примеры:**
- `46269` → 18.09.2026
- `46275` → 24.09.2026
- `46273` → 22.09.2026
- `46210` → 21.07.2025

### 1.3 Выработка (batch_t)
**Проблема:** Все значения `batch_t` в базе =0. Данные отсутствуют.

**Статус:** DATA ABSENT — данные не были загружены при миграции из Google Sheets.

```typescript
function excelDateToDDMMYYYY(serial: string | number | null | undefined): string {
  if (!serial) return '—';
  const s = String(serial).trim();
  if (/^\d{2}\.\d{2}\.\d{4}/.test(s) || /^\d{4}-\d{2}-\d{2}/.test(s)) return s;
  const num = Number(s);
  if (Number.isFinite(num) && num >= 30000 && num <= 60000) {
    const d = new Date(Date.UTC(1899, 11, 30) + num * 86400000);
    const dd = String(d.getUTCDate()).padStart(2, '0');
    const mm = String(d.getUTCMonth() + 1).padStart(2, '0');
    const yyyy = d.getUTCFullYear();
    return `${dd}.${mm}.${yyyy}`;
  }
  return s;
}
```
