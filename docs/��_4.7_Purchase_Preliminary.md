## 1. ФОРМУЛА

```
BASE_STOCK     = AVG_3M
TARGET_STOCK   = MAX(AVG_3M × (1 + purchase_coefficient), min_stock_kg)
AVAILABLE      = PlantStock + LipStock
EXPECTED_SUPPLY = SUM(inbound WHERE active)
PROJECTED_STOCK = AVAILABLE + EXPECTED_SUPPLY - Need
PURCHASE_QTY   = MAX(0, TARGET_STOCK - PROJECTED_STOCK)
```

Все SKU: `purchase_coefficient = 1.0` (по умолчанию).
