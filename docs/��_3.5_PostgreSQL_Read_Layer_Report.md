## 5. Known Issues

1. **PlantStock payload_json неполный** — только 7,333 кг из 179,021 кг. Требуется ре-миграция ТЗ 3.4.
2. **Need расхождения** — PG и Sheets используют разные статусы. Требуется further reconciliation.
3. **Inbound не мигрирован** — getInboundTotals() возвращает пустой Map.
4. **Aliases не мигрированы** — SKU matching по-прежнему использует Sheets.
5. **readSwitch использует env var** — SUPPLY_DATA_SOURCE читается один раз при старте. Для hot-reload нужен restart.
