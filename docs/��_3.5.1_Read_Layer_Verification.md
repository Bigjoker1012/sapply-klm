## 3. Endpoint Comparison: Sheets vs PostgreSQL

### 3.1 SKU / Raw Materials

| Metric | Sheets | PG | Delta |
|--------|-------:|---:|------:|
| Count | 61 | 75 | +14 |

PG has 14 extra SKUs (RAW_004, RAW_005, RAW_012, RAW_022, RAW_030, RAW_034, RAW_041, RAW_044, RAW_047, RAW_048, RAW_050, RAW_054, RAW_061, RAW_063, RAW_064). These exist in recipe/need tables but not in Syryo sheet. They were created during ТЗ 3.3 migration.

**Cause:** Intentional — PG SKU table is superset. Sheets Syryo is incomplete.

### 3.2 Stock (Live)

| Metric | Sheets | PG |
|--------|-------:|---:|
| Plant items | 0 | 0 |
| Lip items | 0 | 0 |

Both return 0 items. The `/api/stock/live` endpoint uses `getLiveStock`/`getStockDeficit` from sheetsService, which are NOT yet migrated to readSwitch. These functions have complex logic that merges PlantStock, LipStock, and Inbound data.

**Cause:** stock.ts read functions (getLiveStock, getStockDeficit) not yet migrated — they still read from sheetsService internally despite the switch.

### 3.3 Recipes

| Metric | Sheets | PG |
|--------|-------:|---:|
| Count | 202 | 191 |
|_statuses| архив=166, план=29, отменён=6, other=1 | active=187, archived=4 |

**Cause:** 
1. 11 recipes difference — some recipes in Sheets not migrated (no recipe_uid match)
2. Status naming: Sheets uses Russian (архив/план/отменён), PG uses English (active/archived)
3. Status semantics differ: Sheets "архив" (166) vs PG "active" (187) — PG "active" includes what Sheets calls "план" and "архив"

### 3.4 Recipe Lines

| Metric | Sheets | PG |
|--------|-------:|---:|
| First recipe lines | 24 | 24 |

Line count matches for the tested recipe. Different recipe_uid returned (PG uses recipe.recipe_uid, Sheets uses Recipes sheet UID).

### 3.5 Planning

| Row count | 61 | 75 |

**Cause:** Planning reads SKU list from readSwitch. PG has 75 SKUs (superset), Sheets has 61. Delta = +14 matches SKU difference.

### 3.6 Dashboard

1. **stock/live returns 0 in both modes** — `getLiveStock`/`getStockDeficit` not yet migrated to readSwitch

3. **14 extra SKUs in PG** — from recipe/need tables, not in Syryo sheet (intentional)
4. **Inbound not migrated** — dashboard/all calls getInboundList from Sheets
5. **Expiry reads LipBatches from Sheets** — not yet migrated
6. **Synonyms/aliases** — only 26 in PG vs 340 in Sheets — not reconciled
