## Ключевые проблемы

### 1. recipe_uid = NULL

Все 191 рецепт в PG имеют **пустой** recipe_uid. Это критическая проблема:
- RecipeLines не могут быть связаны с рецептами
- Need не может быть связан с рецептами
- Связь recipe → recipe_item невозможна

**Причина:** `getRecipesList()` читает `r[0]` как recipe_uid, но данные в Google Sheets имеют пустой столбец A.

**Решение:** Нужно исправить `getRecipesList()` или заполнить recipe_uid вручную.

### 2. stock_snapshot не записан

Ошибка: `import_schema.sql is not a function`
**Причина:** Неизвестная ошибка в функции `getLatestPlantStock()`.

### 3. sku_alias частично записан

26 из 340 записей. Остальные не смаплены (SKU не найден).
