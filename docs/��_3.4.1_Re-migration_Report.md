# ТЗ 3.4.1 — Re-migration PlantStock: Fix qty parsing

**Дата:** 2026-09-19
**Основание:** ТЗ 3.5 reconciliation выявила расхождение PlantStock PG vs Sheets (7,333 кг vs 179,021 кг)

---

## 1. Корневая причина

В скрипте миграции `migrate_stock.js` парсинг qty:

```javascript
const qty = parseFloat(String(r[3] || '0').replace(',', '.')) || 0;
```

Проблема: **не удаляются пробелы**-тысячные разделители.

Google Sheets хранит числа вида `10 426,04` (пробел как разделитель тысяч).

`parseFloat("10 426.04")` → **10** (останавливается на пробеле), вместо **10426.04**.

### Влияние

1156 строк из 3102 имели потерянные пробелы в количестве.

Примеры:

| SKU | Raw value | OLD parser | NEW parser |
|-----|-----------|------------|------------|
| RAW_010 | `10 426,04` | 10.00 | 10426.04 |
| RAW_011 | `7 005,15` | 7.00 | 7005.15 |
| RAW_025 | `76 609,50` | 76.00 | 76609.50 |
| RAW_037 | `10 234,60` | 10.00 | 10234.60 |
| RAW_026 | `1 286,14` | 1.00 | 1286.14 |

---

## 2. Исправление

```javascript
// OLD (buggy)
const qty = parseFloat(String(r[3] || '0').replace(',', '.')) || 0;

// NEW (correct)
function parseQty(v) {
  if (v == null || v === '') return 0;
  const s = String(v).replace(/\s/g, '').replace(',', '.');
  return parseFloat(s) || 0;
}
```
