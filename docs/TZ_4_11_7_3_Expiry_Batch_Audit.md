## 1. ROOT CAUSE

### Проблема 1: Файл не содержит колонок с датами

Файл «КД_18_05_26_Липковская_1779190435513.xls» — это «Ведомость по партиям товаров» из 1С.

**Структура файла:**

| Col 0 | Col 1-2 | Col 3-4 | Col 5-6 | Col 7-8 |
|-------|---------|---------|---------|---------|
| Номенклатура | Нач. остаток (кол/стоим) | Приход (кол/стоим) | Расход (кол/стоим) | Кон. остаток (кол/стоим) |

**В файле НЕТ:**
- Колонки «Дата поставки»
- Колонки «Срок годности»
- Колонки «Номер партии» (отдельной)

**Номер партии** встроен в название: `"Актиген мешок 25 кг. партия IE002856"`

### Проблема 2: Парсер не извлекает даты

Функция `parseKdExcel()` в `excelParser.ts`:

```typescript
// Определяем колонки дат: ищем «Дата поставки» / «Срок годности»
let dateCol1 = nameCol + 1;
let dateCol2 = nameCol + 2;
for (let r = 0; r < Math.min(rows.length, 15); r++) {
    const row = rows[r];
    for (let c = 0; c < row.length; c++) {
        if (/^дата поставки/i.test(String(row[c] || "").trim())) dateCol1 = c;
        if (/^срок годности/i.test(String(row[c] || "").trim())) dateCol2 = c;
    }
}
```

**Результат:** Колонки с датами НЕ НАЙДЕНЫ → `dateCol1` и `dateCol2` остаются значениями по умолчанию (nameCol+1, nameCol+2), которые содержат данные из других колонок.

### Проблема 3: Endpoint /api/expiry не зарегистрирован

Файл `server/src/routes/expiry.ts` СУЩЕСТВУЕТ, но НЕ подключён в `server/src/index.ts`.

```

```

## 3. Где теряется номер партии

**НЕ теряется.** Парсер `parseKdExcel()` извлекает batch_code из названия:

```typescript
const KD_BATCH_RE = /\s*,?\s*партия\s+(\S+)\s*$/i;
const batchMatch = vendorName.match(KD_BATCH_RE);
const batchCode = batchMatch ? batchMatch[1] : "";
```

Пример: `"Актиген мешок 25 кг. партия IE002856"` → `batchCode = "IE002856"`

**Номер партии записывается в БД** в поле `lip_batch.batch_code`.

---

## 4. Где теряется срок годности

**В парсере.** Файл не содержит колонки «Срок годности», поэтому:

```typescript
const expiryDate = parseDate(row[dateCol2]); // dateCol2 указывает на Col 3 (Приход-Количество)
```

`parseDate()` не распознаёт число как дату → `expiryDate = undefined`.

**В БД:** `lip_batch.expiry_date = NULL` для всех28 записей.
