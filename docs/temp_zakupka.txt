5. API:
   - проверить, не возвращает ли backend русский текст в неправильной кодировке.

6. Nginx:
   - проверить конфигурацию отдачи статических файлов;
   - убедиться, что nginx не меняет Content-Type/charset.

7. Сравнить текущую сборку с последним рабочим commit:
   - определить commit, после которого появилась проблема;
   - не откатывать проект сразу;
   - сначала установить причину.

8. Проверить browser DevTools → Network:
   - Response Headers для index.html;
   - Preview/Response;
   - Content-Type;
