## 10. Recommended Migration Sequence

### Phase 1: LipBatches (Critical — blocks Expiry + Upload KD)

1. Create PG table `lip_batch` (columns: id, sku_id, batch_code, vendor_name, qty, expiry_date, manufacture_date, source, created_at)
2. Migrate data from Sheets LipBatches
3. Create PG CRUD: getLipBatchesList, updateLipBatchExpiry, writeLipBatchesBulk, filterKdSimilar
4. Switch expiry.ts, inventory.ts, upload.ts to PG

### Phase 2: RawMaterials CRUD

1. `deleteRawMaterial()` — PG DELETE FROM sku WHERE code = ...
2. `mergeRawMaterials()` — PG transaction (merge aliases, update references, delete source)
3. Switch rawMaterials.ts fully to PG

### Phase 3: Cleanup

1. Fix stock.ts imports (writePlantStock, getStockSnapshots should use readSwitch)
2. Fix recipes.ts partial-archive (replace readRange/writeRange with SQL)
3. Remove dead re-exports from readSwitch
4. Remove unused scripts
5. Remove Sheets fallback from readSwitch (set default=postgres)

### Phase 4: Final Removal

1. Delete sheetsService.ts
2. Remove GOOGLE_SERVICE_ACCOUNT_JSON, GOOGLE_SHEET_ID from .env
3. Remove Sheets-related dependencies from package.json
4. Full regression test
