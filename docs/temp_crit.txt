КРИТИЧЕСКАЯ ПРОБЛЕМА: новый рецепт технолога не появляется в «Рецепты → Активные»

Обнаружен сценарий:

Технолог на Главной странице прикрепляет новый рецепт.
Рецепт появляется в архиве технолога.
В разделе «Склад и рецепты → Рецепты → Активные» этот рецепт отсутствует.
Ничего пока не исправлять

Сначала провести трассировку одного конкретного нового рецепта от момента загрузки до отображения в разделе «Рецепты».

Проверить:

1. Создание

какой endpoint вызывается при прикреплении рецепта технологом;
какая запись создаётся в БД;
в какой таблице;
какой uid;
какой status;
какая version;
есть ли items/состав рецепта.

2. Архив технолога

откуда берёт данные раздел «Архив технолога»;
это та же таблица рецептов или отдельная таблица/хранилище;
почему новый рецепт оказывается именно там.

3. Основной раздел «Рецепты»

какой endpoint загружает рецепты;
какие фильтры применяются для категории active;
попадает ли туда созданный рецепт вообще;
если API его возвращает — почему frontend не показывает;
если API его не возвращает — почему.

4. Статус

Сопоставить фактический статус нового рецепта с действующей моделью:

active / in_work / archived / cancelled

Не делать предположений по названию. Посмотреть фактическое значение в PostgreSQL.

5. Проверить полный маршрут

Прикрепление технологом
      ↓
API
      ↓
PostgreSQL
      ↓
status / version / items
      ↓
API /api/recipes
      ↓
frontend
      ↓
Рецепты → Активные
Особенно важно

Не исправлять проблему изменением статуса вручную и не переводить рецепты из archived в active массово.

Сначала предоставить:

А. UID тестового рецепта
Б. запись этого рецепта в БД
В. его фактический status
Г. endpoint, через который он создан
Д. endpoint списка рецептов
Е. причину, почему он виден в архиве технолога, но отсутствует в Active

Только после этого предложить исправление.

После исправления обязательно протестировать полный сценарий:

технолог прикрепляет рецепт → рецепт появляется в «Рецепты → Активные» → рецепт можно отменить → рецепт можно разбить → после обновления страницы статус сохраняется.
