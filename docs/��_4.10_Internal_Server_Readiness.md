## 5. NGINX — УЖЕ НАСТРОЕН ДЛЯ SUPPLY

Текущая конфигурация `/etc/nginx/sites-enabled/klm-apps.conf`:

```nginx
location /sapply/ {
    proxy_pass http://127.0.0.1:3001/;
    proxy_set_header Host $host;
    proxy_set_header X-Real-IP $remote_addr;
}
```

**Supply уже проксируется через nginx на внутреннем сервере!** Нужно только запустить Node.js на порту 3001.

### Минимальные действия для запуска

```bash
# 1. Установить PyMuPDF
pip3 install PyMuPDF

# 2. Скопировать код с VPS
rsync -avz root@72.56.239.5:/opt/sapply-klm/ /opt/sapply-klm/

# 3. Создать БД
sudo -u postgres createdb erp_supply

# 4. Импортировать данные
pg_dump ... | psql erp_supply

# 5. Настроить .env (PORT=3001, DATABASE_URL=localhost)

# 6. Установить зависимости
cd /opt/sapply-klm && npm install

# 7. Собрать
npm run build

# 8. Запустить
pm2 start start.sh --name supply-klm
```

### Не трогать

- VPS Timeweb (оставить как резерв)
- DNS (не менять до решения)
- Docker контейнеры Keenan/BUTB
- Существующие nginx locations
