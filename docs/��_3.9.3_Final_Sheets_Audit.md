## 6. Partial-Archive Analysis

**Текущая реализация** (recipes.ts, строки 172-237):
1. `readRange("Recipes", "A2:M5000")` — найти рецепт
2. `readRange("RecipeLines", "A2:L5000")` — найти строки
3. `writeRange("Recipes", ...)` — обновить batch_t
4. `writeRange("RecipeLines", ...)` — обновить consumption
5. Создать новый рецепт через `writeRecipePG`
6. Записать RecipeLines через `writeRecipeLines` (Sheets)
7. Записать Need через `writeNeedFromRecipePG`

**PG replacement:** Транзакционный SQL:
```sql
UPDATE recipe SET batch_t = $1, base_batch_kg = $2 WHERE recipe_uid = $3;
UPDATE recipe_item SET consumption_kg = consumption_kg * $4 WHERE recipe_id = $5;
-- create new recipe + items + need in transaction
```
