## Сверка consumption_kg

### Глобально

| Источник | Значение |
|----------|----------|
| Sheets RecipeLines | 108 221,718 кг |
| PG recipe_item | 90 223,893 кг |
| Разница | 17 997,825 кг |

### Причина разницы

40 строк RecipeLines имеют **пустой raw_uid** (нет SKU в каталоге):
- Все — "ОТРУБИ РЖАНЫЕ/ПШЕНИЧНЫЕ"
- Consumption: 17 804,288 кг
- Строка +.recipe.uid = REC_1788357812384 и др.

Эти строки **не могут быть импортированы** в recipe_item, т.к. raw_uid отсутствует.

### Итого

| Категория | Количество | Consumption |
|-----------|-----------|-------------|
| Импортировано в PG | 809 | 90 223,893 |
| Пустой raw_uid (не может) | 40 | 17 804,288 |
| Нет SKU (не импортировано) | 3 | ~393 |
| **Итого в Sheets** | **852** | **108 221,718** |

**Разница объяснена:** 40 строк с пустым raw_uid + 3 строки с несуществующим SKU.
