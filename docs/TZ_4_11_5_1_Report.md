**Дата:** 2026-09-21

## 1. Выполненные изменения

### 1.1 База данных — sku_alias таблица

**Добавлены поля:**
- `created_at TIMESTAMPTZ DEFAULT now()` — дата добавления
- `created_by INTEGER REFERENCES "user"(id)` — кто добавил

**Добавлен constraint:**
- `UNIQUE (alias)` — защита от дубликатов

### 1.2 Backend — postgresSupplyService.ts

**Обновлена функция pgAddAlias:**
- Принимает `userId` параметр
- Сохраняет `created_by` при добавлении
- Обрабатывает дубликаты через `ON CONFLICT (alias) DO UPDATE`

### 1.3 Backend — synonyms.ts

**Обновлены роуты:**
- `POST /api/synonyms` — передаёт `req.user?.id` как userId
- `POST /api/synonyms/confirm` — передаёт `req.user?.id` как userId

### 1.4 Backend — readSwitch.ts

**Обновлена функция addAlias:**
- Принимает `userId` параметр
- Проксирует в pgAddAlias

## 2. Проверка работы

### 2.1 API работает
- `POST /api/synonyms` — добавляет синонимы ✅

- `created_by` сохраняется ✅

### 2.2 Защита от дубликатов
- При повторном добавлении того же синонимо — `ON CONFLICT DO UPDATE` ✅

### 2.3 Отслеживание
- `created_at` заполняется автоматически ✅
- `created_by` заполняется при авторизованном запросе ✅
