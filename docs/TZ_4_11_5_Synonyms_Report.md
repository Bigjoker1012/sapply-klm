## 1. Выполненные изменения

### 1.1 Frontend — Dashboard.tsx

**Добавлен чекбокс «Запомнить» в UnmatchedRow компонент:**

- Чекбокс по умолчанию включён (rememberAlias = true)
- При подтверждении нераспознанной строки с включённым чекбоксом система сохраняет исходное название как синоним
- При выключенном чекбоксе синоним не сохраняется (строка привязывается без обучения)

**Изменения в коде:**

### 1.2 Backend — postgresSupplyService.ts

**Исправлен баг в pgAddAlias:**
- Удалена несуществующая колонка `canonical_raw_uid` из INSERT
- Исправлено количество значений в VALUES (было4, стало3)

**До:**
```sql
INSERT INTO sku_alias (sku_id, alias, canonical_raw_uid, source)
VALUES (${skuId}, ${alias}, ${rawUid}, ${source || 'manual'})
```

**После:**
```sql
INSERT INTO sku_alias (sku_id, alias, source)
VALUES (${skuId}, ${alias}, ${source || 'manual'})
```
